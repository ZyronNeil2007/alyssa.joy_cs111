# Sari-Sari Memories

**Version:** 1.0.0

A static, sari-sari-store-themed memory site with eight sections: childhood, family, friends, love, favorite food, favorite movies, favorite songs, and jokes.

## Features

- Animated navigation between the store and memory pages
- Photo galleries with an image viewer
- Tabbed movie and song information
- A recipe and interactive joke answers
- Responsive layout with no build step or runtime dependencies

## Run locally

With Python 3 installed, start a static server from the project directory:

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000> in a browser.

## Media

The photo galleries use the image files included in this repository. Video clips are not distributed here; the movie and song pages show a note in place of video players. Only add clips when you have the rights to publish them.
